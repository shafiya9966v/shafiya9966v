### 🚀 Featured Projects

#### 🏥 [AI HealthMate](https://github.com/shafiya9966v/AI_Healthmate)
A multi-disease prediction web app built with Flask, bringing together several independent ML models into one platform:
- **Diabetes prediction** (Logistic Regression / classification models)
- **Cardiovascular disease risk prediction** (Gradient Boosting)
- **Anemia detection** from CBC blood data
- **Pneumonia classification** from image data using a deep learning model (Keras/TensorFlow, `.h5`)
- **Parkinson's disease detection**
- **Lung cancer risk prediction**
- **Tinnitus risk assessment** and a **biological-age ("bioclock") estimator**
- A **patient triage model** for prioritizing cases
> Tech: Python, Flask, scikit-learn, TensorFlow/Keras, Pandas, NumPy

#### ❤️ [Cardiovascular Disease Prediction](https://github.com/shafiya9966v/cardio-predict-using-machie-learningg-)
An ML model to predict cardiovascular disease risk using patient health data (cholesterol, alcohol use, height, weight, age, gender, etc.). Covers data preprocessing, exploratory data analysis, visualization, and model accuracy evaluation.
> Tech: Python, Pandas, scikit-learn, Jupyter Notebook

#### ⚙️ [Industrial Equipment Anomaly Detection](https://github.com/shafiya9966v/equipment.diploy)
An anomaly detection system for industrial equipment using an SVM classifier, deployed as a standalone app to flag abnormal equipment behavior before failure occurs.
> Tech: Python, scikit-learn (SVM), Flask/Streamlit deployment

#### 📦 [Sustainable Supply Chain Performance](https://github.com/shafiya9966v/Sustainable-Supply-Chain-Performance)
A Power BI dashboard analyzing supply chain performance through a sustainability lens — tracking key metrics across a multi-week analysis process, from raw data to final report.
> Tech: Power BI, DAX, Data Modeling
